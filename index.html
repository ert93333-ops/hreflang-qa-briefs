FAQ

Localization constraints are explicit.

Does it crawl my site?

No. This MVP only analyzes pasted localized URL maps and HTML head snippets.

Does it guarantee indexing?

No. It catches common hreflang launch blockers but does not promise ranking or indexing outcomes.

Do I need Search Console?

No. It is built for prelaunch QA before post-launch Search Console data exists.

Can I paste private client URLs?

Use public-safe or anonymized data. The workflow is browser-local, but the MVP is not a secure client portal.
