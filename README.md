# Hreflang QA Briefs

Browser-local MVP for checking pasted localized URL maps and HTML head snippets before multilingual pages launch.

Public URL:

- https://ert93333-ops.github.io/hreflang-qa-briefs/

Core workflow:

- Paste localized URL map rows and HTML head snippets.
- Generate a hreflang QA brief for missing self-references, reciprocal-link gaps, canonical conflicts, invalid codes, relative URLs, duplicate variants, and x-default gaps.
- Request early access or copy a public-safe demo request.
